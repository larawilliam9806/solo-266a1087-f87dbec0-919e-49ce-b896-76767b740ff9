# 水质实验室 · 批次修订发布台

供水质实验室数据员使用的批次修订发布页（Flask + SQLite）。浏览器上传仪器导出的
CSV、填写批次号，系统逐行校验后预览**新增 / 修改 / 撤回（删除）**差异，确认后
**整批替换**下游采集程序读取的本地 CSV，并在网页登记当前版本与行数。

统计人员使用**标样校正后的检测浓度**：在「标样校正」页为每个检测项目录入两组
标样（仪器读数 ↔ 真实浓度），由两点确定线性校正关系，一键换算当前已发布批次的
全部结果，确认后生成独立的校正 CSV 供数；原始发布 CSV 供数完全不受影响。

## 功能与规则

### 批次发布（原始数据）

- 上传 CSV 必须包含三列（表头兼容中英文）：`样本号`、`检测项目`、`浓度(mg/L)`
  （亦接受 `sample_no / analyte / concentration` 等常见别名，UTF-8、支持 BOM）。
- 逐行业务校验，错误带行号提示：
  - 同一样本同一检测项目不得重复；
  - 浓度必须是数字且 **≥ 0**（拒绝负数、空值、NaN、Inf、非数字）；
  - 样本号、检测项目不能为空，列数必须与表头一致。
- 上传内容代表修订后的**完整一批**：当前版本中存在、但本次 CSV 未包含的行，
  在预览中列为「撤回（删除）」，确认后该检测结果即被撤回。
- 预览页分类展示新增、修改（旧值→新值）、撤回、不变四类差异，确认后才发布。
- 首页登记当前版本号、批次号、行数、发布时间（UTC）与内容 SHA256，并提供
  已发布 CSV 的在线查看入口和事件日志（含每次恢复记录）。

### 标样校正（统计人员供数）

- **标样录入**：每个检测项目一行，录入**两组**「仪器读数 / 真实浓度」。
  录入校验：两组读数必须不同；全部数值**有限且非负**；同一项目只录一行。
  保存即生成新标样集版本（内容与当前版本完全一致时复用原版本）。
- **两点线性换算**：由两点确定 `浓度 = k × 读数 + b`，对当前已发布批次的
  全部结果逐行换算。出现以下任一情况时**整版校正数据不可供数**并逐条显示原因：
  - 发布数据中的检测项目**缺少标样**；
  - 某项目校正**斜率不为正数**（或非有限值）；
  - 任一行换算结果为**负值**或**非有限值**。
- **确认才生效**：换算预览不生成任何文件，**未确认的新数据不可下载**；
  确认后生成独立的校正 CSV（`downstream/calibrated_results.csv`），
  注释头记录**原始发布版本与所用标样集**，数据列含原始读数与校正后浓度。
- **失效与追溯**：新批次发布或标样修改后，旧校正立即失效、供数文件撤下，
  **不得作为当前数据下载**；旧校正文件在校正页「校正历史」中**按原版本追溯下载**。
- **交错防护**：校正确认与发布、标样修改交错时，确认在写事务内复核
  「发布版本 + 标样集」与预览时完全一致，任一变化即拒绝（409），
  **绝不固化混合状态**；换算/确认失败时**上次完整校正结果原样保留**。

## 启动方式

### Docker Compose（推荐）

```bash
cd wq-publish
docker compose up -d --build     # 监听 http://127.0.0.1:5000
```

数据持久化在命名卷 `wq-data`（SQLite 登记、密钥、隔离区、校正归档）与
`wq-downstream`（下游采集程序读取目录）中；容器内以 waitress 提供服务。

### 本地启动

环境要求：Python 3.10+（依赖 Flask + waitress）。

```bash
cd wq-publish
./run.sh                 # 自动创建 .venv、安装依赖，监听 http://127.0.0.1:5000
```

手动方式：

```bash
python3 -m venv --without-pip .venv   # 若系统带 ensurepip，直接 python3 -m venv .venv
# 按你的环境引导 pip 后：
.venv/bin/pip install -r requirements.txt
WQ_DATA_DIR=$PWD/data WQ_DOWNSTREAM_DIR=$PWD/downstream \
  .venv/bin/flask --app wsgi:create_app run --host 127.0.0.1 --port 5000
```

环境变量（可选）：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `WQ_DATA_DIR` | `./data` | SQLite 数据库、flask 密钥、隔离区、校正归档存放目录 |
| `WQ_DOWNSTREAM_DIR` | `./downstream` | 下游读取目录：原始 `published_results.csv` + 校正 `calibrated_results.csv` |

下游采集程序固定读取 `WQ_DOWNSTREAM_DIR/published_results.csv`（原始数据）；
统计人员读取 `WQ_DOWNSTREAM_DIR/calibrated_results.csv`（校正后数据，仅当前生效校正）。

## 操作流程

### 批次修订发布

1. 打开首页，填写批次号并选择仪器导出的 CSV，点击「校验并预览增删改」。
2. 校验失败：回到首页逐条显示带行号的错误，修正后重新上传，不产生任何数据变更。
3. 校验通过：进入预览页核对新增/修改/撤回差异，可「放弃本次修订」或
   「确认无误，整批替换并发布」。
4. 发布成功后回到首页，登记版本号递增、行数更新，下游文件已原子替换。

### 标样校正供数

1. 进入「标样校正」页，录入各检测项目的两组标样读数与真实浓度，保存标样集。
2. 点击「换算并预览」：任一项目缺标样、斜率非正、结果负值/非有限时，
   整版不可供数并列出全部原因，修正标样后重试。
3. 预览页核对每行「原始读数 → 校正后浓度」，确认后校正 CSV 生效供数。
4. 新批次发布或标样修改后，当前校正自动失效，需重新换算确认；
   历史校正可在校正历史中按原版本追溯下载。

## 数据一致性设计（如何保证要求）

**下游只会读到完整旧版或新版**

- 发布/校正均先把新 CSV 写入下游目录内的同目录临时文件（`.tmp-publish-*` /
  `.tmp-calibrate-*`），`flush + fsync` 后 `os.replace` 原子改名，并 fsync 目录。
  改名瞬间下游要么看到旧文件、要么看到完整新文件，不会读到半写内容。

**文件与登记的事务关系、崩溃自动恢复**

- SQLite（`data/wq_publish.db`）是版本登记、全版本结果、标样集与校正记录的
  唯一真相源，发布/校正确认均在 `BEGIN IMMEDIATE` 事务内完成
  「原子换文件 → 落库登记」。
- 每次启动（`Storage.recover()`）自动核对并修复：
  1. 清理崩溃遗留的临时文件；
  2. 原始/校正供数文件缺失或 SHA256 与登记不符时，以数据库登记为准原子重建；
  3. 「文件已改名但事务未提交」的现场，重启后回滚为登记中的完整版本；
     无生效校正登记时，下游校正文件一律隔离，不作为当前数据供数；
  4. 下游目录与校正归档目录中未登记的游离文件移入 `data/quarantine/` 隔离；
  5. 超过 24 小时未确认的预览/校正会话自动作废。
  所有恢复动作写入 `event_log` 并展示在首页。

**两个页面从同一版本发起修订/校正，只允许一个成功**

- 发布预览与校正预览均生成带随机 token 的会话，记录基线（发布版本 /
  发布版本+标样集版本）。确认时在写事务内重新比对：基线已被超越则会话
  标记 `obsolete` 并返回 409 过期页，明确要求重新预览，绝不覆盖先发布者、
  绝不固化「新发布 + 旧标样」之类的混合状态。
- 同一会话重复确认、已取消/已确认/已过期会话再次确认，一律拒绝。

**校正的失效与追溯**

- 校正记录绑定「原始发布版本 + 标样集版本」。新批次发布或标样修改在同一
  事务内把当前校正标记 `superseded` 并撤下下游供数文件；归档副本保留在
  `data/calibration_archive/`，校正历史页可按原版本追溯下载。
- 换算失败、确认冲突、会话取消都不触碰已生效/已归档的校正结果。

## 部署提示与已知限制

- `flask run` 为开发服务器；正式环境用容器（`docker compose up`）或
  `waitress-serve --host 127.0.0.1 --port 5000 --call wsgi:create_app`
  （或 gunicorn 单实例多线程）。并发正确性依赖 SQLite 的 `BEGIN IMMEDIATE`
  文件锁与同目录 `os.replace`，多 worker 部署时必须共享同一个
  `WQ_DATA_DIR` 与 `WQ_DOWNSTREAM_DIR`。
- 全量结果按版本保留在 `results` 表中，当前未提供历史版本回滚的页面入口
  （数据具备，可后续增加）；历史原始 CSV 文件本身只保留最新一版，
  历史校正 CSV 以归档文件形式全量保留。
- 上传上限 16MB；认证、权限控制未包含在本版本内，建议仅监听内网或前置反向代理
  加访问控制。
